## What was the reported air temperature in degrees Celsius? (give your answer to one decimal place i.e. "12.3")

Decoding the challenge audio signal using International Morse Code produces a radio message containing station call signs alongside a sequence of 13 five-digit groups

![10. Synoptic Code.png](./images/10.%20Synoptic%20Code.png)

Stripping away the CW procedural framing at both ends, `RCV DE UCTA5` identifies `RCV` as the receiving station, the prosign `DE` meaning "from", and `UCTA5` as the transmitting vessel's radio call sign, while `BT AR UCTA5 N` at the tail marks the break and end of transmission. The body of five-digit blocks follows the international marine synoptic standard **WMO FM 13 (SHIP)**, omitting the leading `BBXX` ship report indicator and starting directly with the observation time block

```text
RCV DE UCTA5 13181 99345 10346 41698 32405 10280 40120 54000 70200 83500 22252 00280 13012 BT AR UCTA5 N
```

Cross-referencing the encoding layout in the NOAA/NWS [ObservingHandbook](https://www.weather.gov/media/owlie/ObservingHandbook1_2010_508_compliant.pdf), WMO FM 13 packs surface marine observations into fixed five-digit numeric groups to keep transmissions compact over noisy HF radio links. So that a receiving station can still parse each parameter when optional sensors are omitted (for instance, this report skips group `2` for dew point and group `6` for precipitation), the format relies on a three-section layout keyed by leading group indicators

![10. Synoptic Code-1.png](./images/10.%20Synoptic%20Code-1.png)

Section 0 covers time and ship coordinates, opening with `YYGGiw` followed by a latitude block prefixed with `99` and a longitude block prefixed by the quadrant code `Qc`. Section 1 carries surface meteorological data starting with two mandatory blocks, `iRixhVV` and `Nddff`, after which every optional block uses its first digit as a field identifier (`1` for air temperature, `4` for sea-level pressure, `5` for pressure tendency, `7` for weather, and `8` for clouds). Section 2 switches to oceanographic measurements with the `222` section marker

| Code Group | WMO Structure | Decoded Values |
| --- | --- | --- |
| `13181` | `YY GG iw` | Day `13`, time `1800 UTC`, wind speed measured by instrument in m/s (`1`) |
| `99345` | `99 LaLaLa` | Position prefix `99`, latitude `34.5°` |
| `10346` | `Qc LoLoLoLo` | Quadrant `1` (North, East), longitude `34.6°` |
| `41698` | `iR ix h VV` | Precipitation omitted (`4`), manned station with weather group (`1`), lowest cloud base `1,000-1,500 m` (`6`), visibility `20 km` (`98`) |
| `32405` | `N dd ff` | Total cloud cover `3 oktas`, wind direction `240°`, wind speed `5 m/s` (`05`) |
| `10280` | `1 sn TTT` | Air temperature group (`1`), positive sign (`0`), value `+28.0 °C` |
| `40120` | `4 PPPP` | Sea-level pressure (`4`), value `1012.0 hPa` (leading `1` in thousands omitted) |
| `54000` | `5 a ppp` | Three-hour pressure tendency (`5`), steady (`4`), net change `0.0 hPa` |
| `70200` | `7 ww W1 W2` | Present weather (`02`, state of sky unchanged), past weather `0` and `0` |
| `83500` | `8 Nh CL CM CH` | Low cloud cover `3 oktas`, *Stratocumulus* not formed from *Cumulus* (`5`), no middle (`0`) or high (`0`) clouds |
| `22252` | `222 Ds Vs` | Maritime section (`222`), ship moving `SW` (`5`) at `6-10 knots` (`2`) |
| `00280` | `0 Ss TwTwTw` | Sea-surface temperature group (`0`), positive sign (`0`), value `+28.0 °C` |
| `13012` | `1 PwPw HwHw` | Instrumental wave data (`1`), wave period `30 seconds`, wave height `6.0 m` (`12` half-meters) |

To isolate the reported air temperature, we examine block `10280` under the `1snTTT` format. The leading `1` marks dry-bulb air temperature, `sn = 0` denotes a non-negative value (`0` for `>= 0 °C`, `1` for `< 0 °C`), and the remaining three digits `TTT = 280` encode the temperature in tenths of a degree Celsius without a decimal point. Converting `280` gives `+28.0 °C`

> 28.0
